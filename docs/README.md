# Documentation

## Opérations

- `MODULAR-UPDATES.md` décrit la publication des mises à jour Training et Nutrition tout en préservant les données locales.
- `CLIENT-PACKAGE.md` définit les trois fichiers canoniques et les règles d’identité, de stockage et de validation.

## Historique

Le dossier `releases/` conserve les notes des versions antérieures du portail. Ces fichiers documentent l’évolution du produit; ils ne sont pas chargés par l’application et ne doivent pas être copiés dans les portails clients générés.
